# TikTok-LS-CLI\n\nLightweight local control-plane CLI for device discovery, camera/microphone selection, diagnostics and PAOKRA integration.\n\n## Deliberate scope\n- No video/image/screen source system: PAOKRA owns composition and can feed a virtual camera later.\n- No stream-key/token arguments.\n- Stable device IDs are derived from DirectShow alternative names.\n- JSON output is available for automation with `--json`.\n- LIVE commands are read-only in this initial build; no credential bypass or LIVE activation is implemented.\n\n## Examples\n`tiktokls devices camera list`\n`tiktokls devices microphone list`\n`tiktokls devices camera capabilities <device-id>`\n`tiktokls camera select <device-id>`\n`tiktokls camera test <device-id>`\n`tiktokls audio select <device-id>`\n`tiktokls config show`\n`tiktokls diagnostics capabilities --json`\n
