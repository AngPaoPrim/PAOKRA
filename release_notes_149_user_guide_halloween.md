# PAOKRA Studio v1.4.9 — User Guide & Halloween Theme

## Added
- A polished, tabbed Thai user guide opens automatically at startup.
- Users can close the guide temporarily, opt out of automatic display, and re-enable startup display from Settings.
- The guide can be reopened from Settings and covers first-run setup, Live Console, Virtual Camera, Clip Flow, AI Seam / Auto Make Frames, appearance settings, updates, and common troubleshooting.
- Added a Halloween appearance preset with pumpkin-orange and night-purple accents.
- Added a small Easter egg credit for OOMSIN, who suggested improvements.

## Safety / scope
- The guide is an isolated frontend module and does not alter playback, seam generation, Virtual Camera, backend, or updater logic.
- Existing 1.4.8 seam and updater behavior remains unchanged.

## Halloween polish and OOMSIN Easter egg
- Added a subtle Halloween atmosphere to the guide overlay with warm pumpkin-orange accents, violet ambient lighting, and responsive decorative details.
- Added a small OOMSIN thank-you Easter egg in the guide only; it does not change application workflows or settings.
- Added a focused QA script for the Easter egg and packaged guide asset integrity.
