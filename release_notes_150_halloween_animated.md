# PAOKRA Studio v1.5.0 — Animated Halloween Background

## Halloween background
- Replaced the static Halloween glow with a slow, animated orange-pumpkin and violet gradient.
- Animated the ambient aurora layer so the background softly drifts between warm orange and purple light.
- Added a subtle floating pumpkin accent to complete the Halloween atmosphere.
- Motion is CSS-only: no new packages, video loops, or large background assets.
- Respects the operating system's reduced-motion preference; the existing animation setting can also disable animations.

## Stability and scope
- Kept the existing guide, OOMSIN Easter egg, and app workflows intact.
- Only the guide stylesheet, guide version comment, desktop package version, and release/QA notes were changed for this release.
